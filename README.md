# Kalymnos Tourism Website

A multi-page tourism website dedicated to Kalymnos, a Greek island in the Dodecanese.

This was my **first web development project**, created individually from scratch during my first semester at university, using HTML and CSS without any templates or frameworks.

## Live Website

**[View the Website](https://kchatzidaki.github.io/kalymnos-tourism-website/)**

## About the Project

The website introduces visitors to the island of Kalymnos, highlighting its history, culture, traditions, landmarks, and local attractions.

It features multiple interconnected pages with a consistent navigation menu, images, and informational content in Greek.

## Technologies Used

- HTML5
- CSS3

## Features

- Multi-page website with navigation between sections
- Information about Kalymnos and its attractions
- Pages dedicated to local history, museums, castles, and traditions
- Images accompanying the informational content
- Custom styling using CSS

## How to Run

You can explore the website directly through the [live demo](https://kchatzidaki.github.io/kalymnos-tourism-website/).

Alternatively:

1. Download or clone this repository.
2. Open `index.html` in a web browser.

No additional installation is required.
